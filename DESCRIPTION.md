# SeanPak — repo metadata

## Description (GitHub About)
Native Windows installer packager built for AI-driven packaging: one command turns a manifest and program files into Setup.exe + Portable.zip + SHA256SUMS.txt — per-user installs with rollback, optional components, hooks, journaled writes, Modify mode, full CLI/JSON control. Offline, zero telemetry.
